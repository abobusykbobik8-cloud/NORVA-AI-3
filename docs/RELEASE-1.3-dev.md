# NØRVA AI 1.3-dev

Тестовая версия локального Android-ассистента с чатом, историей и вопросами по фотографиям. Работает на Android 10 и новее с 64-битным ARM-процессором.

## Изменения

- Системная инструкция, роли, история и блок рассуждений оформляются по шаблону Qwen3.5. Введённые в сообщении служебные маркеры экранируются. Длинные дословные повторы останавливаются с сохранением частичного ответа.
- Добавлена Qwen3.5 0.8B Q4_K_M для устройств с 3–4 ГБ. Загрузка модели занимает 533 МБ, для фотографий нужен её отдельный проектор на 205 МБ. При выборе контекста учитываются доступная память, системный порог и запас под изображение.
- Локальный чат получает пиксели через mtmd. Поддерживаются вопросы по фотографии, скриншоту и снимку документа. Можно уточнить вопрос по последнему снимку. При нехватке памяти или отсутствии проектора приложение показывает причину.
- Fast, Normal и Deep используют разные лимиты ответа. Длительное рассуждение доступно у 2B и 4B. Улучшены отмена генерации, докачка моделей и ограничение памяти очереди токенов.
- Чат открывается с последнего диалога. В выдвижной панели доступны история, поиск по названиям и выбор чатов с фото или видео. Режим меняется нажатием на верхнюю капсулу. Поле ввода и кнопки оформлены в прежних цветах Liquid Glass.
- Обновлены карточка памяти, индикаторы и красно-синий переключатель Liquid Glass. На устройствах до 4 ГиБ фон сохраняет градиенты без постоянной анимации. Добавлена адаптивная иконка, в том числе для тематических значков Android.
- Сохранены история, настройки и процедурный Canvas. Облачный чат настраивается через HTTPS API, для нейросетевых изображений и видео предусмотрены FLUX и Wan через ключ fal.ai. Работа платной генерации с аккаунтом провайдера ещё не проверена.

## Установка

1. Для проверки рядом с 1.2 откройте **NORVA-AI-1.3-dev-preview.apk**. Эта копия называется **NØRVA AI · Тест** и использует собственные чаты и модели. Основной APK **NORVA-AI-1.3-dev.apk** можно установить поверх прежней версии при совпадающей подписи. Подпись опубликованной 1.2 beta отличается. Если она уже установлена, выберите тестовую копию, чтобы сохранить старые чаты.
2. В «Моделях» скачайте 0.8B для слабого устройства или 2B/4B при достаточной памяти. Для фото нужен F16-проектор того же размера модели. Весов внутри APK нет.
3. Откройте чат, нажмите «+», выберите снимок и отправьте вопрос. Для документов лучше выбрать крупный читаемый фрагмент.

## Проверка

Собраны release APK, проверены подписи. Прошли 88 JVM-тестов. В Android Lint нет ошибок. На настоящей 2B проверены все три режима и отделение рассуждений в Deep. На тестовой машине 0.8B прочитала четыре латинских слова и газетный заголовок, допустила ошибку в кириллице. Аппаратные показатели на телефонах ещё не измерялись. Сборки подписаны тестовым сертификатом.
