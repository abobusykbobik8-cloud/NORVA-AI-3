# NØRVA AI 1.4 бета

Android-ассистент с локальными моделями Qwen3.5. В этой версии появился раздел **Настройки → NØRVA Studio**. Модели для локальных функций скачиваются отдельно.

## Что изменилось

- **MultiBrain** требует две разные установленные модели. Каждая отвечает на исходный вопрос самостоятельно, затем проверяет ответ другой. В результате видны итог, оба ответа и замечания. Модели занимают память по очереди.
- **Deep Research** ищет статьи Wikipedia и аннотации Crossref. Локальная модель сопоставляет до четырёх выдержек и проверяет черновик по ним. В отчёте доступны ссылки на первоисточники. Если модель не указала подходящие ссылки, приложение показывает выдержки. Для поиска нужен интернет, ключ API не требуется.
- **Memory 2.0** хранит до 32 добавленных вручную предпочтений. Их можно просмотреть и удалить. Подходящие записи учитываются в локальном чате. Для шифрования используется ключ Android Keystore.
- **Model Hub** показывает размер загрузки и ориентировочную потребность в ОЗУ. Можно скачать, удалить или закрепить модель и вернуться к автовыбору. **Turbo** при автовыборе предпочитает меньшую подходящую модель и сокращает контекст и бюджет ответа. Сохраняются режимы Fast, Normal, Deep и защита при перегреве.
- **NØRVA Benchmark** выполняет три коротких задания по арифметике, извлечению слова и классификации. Отдельно показывает точные совпадения, завершённые задания, токены в секунду и память процесса на границах заданий. Это короткая проверка конкретной модели.
- **Liquid Glass 2.0** размывает фон стеклянных панелей на Android 12+ при объёме ОЗУ свыше 4 ГиБ. На слабых устройствах используется облегчённое оформление. Сохранены прежняя палитра, шрифты и навигация.
- **Cross Sync** по команде объединяет завершённые текстовые сообщения без дублей. По выбору переносит системную инструкцию, режим и Turbo. Доступны зашифрованный файл и HTTPS WebDAV с поддержкой сильного ETag. Для сетевого обмена нужен свой сервер. Вложения, ключи API и персональная память остаются на устройстве. Формат архива использует AES-256-GCM и PBKDF2. Основная база чатов хранится в закрытом каталоге Android, отдельного шифрования этой базы в приложении нет.
- **NØRVA Live** открывается из меню чата. Распознаёт речь с промежуточным текстом, отправляет фразу в чат и читает ответ вслух. Кнопка «Перебить и говорить» останавливает ответ и включает микрофон. Нужны разрешение микрофона и системные службы распознавания и синтеза речи. Возможность работы офлайн зависит от устройства и голосовых пакетов.

## Установка

1. На Android 10+ с процессором ARM64 откройте **NORVA-AI-1.4-beta.apk**. Для обновления тестовой копии 1.3 или установки рядом с 1.2 используйте **NORVA-AI-1.4-beta-preview.apk**. У основной и тестовой копий отдельные чаты и модели. Сборки подписаны тем же тестовым сертификатом, что и 1.3.
2. В разделе моделей скачайте Qwen3.5 0.8B для устройства с 3–4 ГБ или 2B/4B при достаточной доступной памяти. Для фото установите совместимый проектор из того же раздела. Для MultiBrain установите вторую текстовую модель.
3. На ПК для Cross Sync нужны Python 3 и пакет cryptography. Установите его командой `python -m pip install cryptography`. Скачайте из Assets файл `norva_sync.py`. Создайте архив на телефоне и передайте на ПК либо синхронизируйте через свой WebDAV.

Прочитать список чатов из файла:

```sh
python norva_sync.py norva-1.4.nvault
```

Добавить сообщение в существующий чат и сохранить зашифрованный результат для импорта на телефоне:

```sh
python norva_sync.py norva-1.4.nvault --chat UUID --add --output updated.nvault
```

Для обмена по сети укажите вместо имени файла `--dav https://server.example/path/norva.nvault --user LOGIN`. Пароли вводятся по запросу. Нужен пароль архива длиной от 12 символов.
