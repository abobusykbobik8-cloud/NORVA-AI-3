# Сборка и установка

Проект использует Gradle 8.10.2, JDK 17, AGP 8.7.3, Android SDK 35, NDK 27.2.12479018 и CMake 3.22.1. Установите эти компоненты и задайте ANDROID_HOME. Для локальной сборки из корня проекта выполните следующие команды.

```sh
sh scripts/fetch_llama.sh
gradle :core-policy:test :core-inference:test :core-chat:test :core-vision:test
sh native-check/run.sh
sh native-check/verify_real_llama.sh third_party/llama.cpp
gradle :app:assembleRelease :app:lintRelease
```

Unsigned APK находится в `app/build/outputs/apk/release/`. Для выпуска подпишите его ключом приложения. Сборка с `-Pnorva.previewInstall=true` использует отдельный пакет `ai.norva.mobile.preview` и устанавливается параллельно. Репозиторий также содержит workflow `ci` для сборки debug APK в GitHub Actions.

## На телефоне

Нужен Android 10 или новее и 64-битная система ARM. Откройте подписанный APK в файловом менеджере и подтвердите установку. Android устанавливает обновление поверх имеющегося приложения только при совместимой подписи и номере версии. При конфликте подписи используйте отдельный APK «Тест». Он сохраняет прежнюю установку, чаты и модели основной версии. У тестовой копии своя база, настройки и загрузки.

В «Моделях» выберите 0.8B для телефона с 3–4 ГБ или 2B/4B при достаточном запасе памяти. Для первого текстового запроса достаточно GGUF. Для фотографий дополнительно скачайте проектор той же модели. Скачивание проверяется по SHA-256 Hugging Face и может продолжиться после паузы.
