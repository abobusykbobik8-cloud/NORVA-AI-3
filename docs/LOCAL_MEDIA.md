# Локальная генерация

В Model Hub скачайте **Картинки · Stable Diffusion 1.5** (1,57 ГБ) или все три компонента **Видео** (Wan VACE, UMT5, Wan VAE, вместе 4,46 ГБ). После проверки файлов по SHA-256 генерация работает на CPU телефона в авиарежиме. Модель чата для этого не требуется.

Введите запрос, откройте **+ → Локально** и выберите изображение или видео. Для видео по фото сначала прикрепите снимок, затем напишите, какое движение хотите увидеть. Для SD 1.5 используйте запрос на английском. Готовую работу можно сохранить из чата в галерею.

Изображение сохраняется как PNG 384×384. Видео сохраняется как MP4 256×256, 9 кадров при 6 кадрах/с. Это короткий ролик без звука. Результаты зависят от модели, запроса и случайного начального шума. Загрузка весов и вычисления на CPU могут занять несколько минут. Кнопка остановки прерывает вычисление. При перегреве или системном предупреждении о нехватке памяти приложение также останавливает генерацию.

Ориентир доступной памяти при старте составляет 3 ГиБ для SD и 6 ГиБ для Wan сверх системного резерва. Свободная память ниже номинального объёма устройства. Скорость и нагрев на realme GT 8 Pro требуют измерения на самом телефоне.

Для сборки сначала выполните `sh scripts/fetch_llama.sh` и `sh scripts/fetch_diffusion.sh`, затем обычную команду Gradle. Приложение собирает отдельный нативный процесс с закреплёнными ревизиями stable-diffusion.cpp и ggml. Веса моделей загружаются отдельно по выбору пользователя.
