# Статус проекта

В среде разработки нет Kotlin-компилятора, Gradle, Android SDK, NDK, настоящих `llama.h` и `jni.h` и сети для сборки.
Поэтому **Kotlin и C++ не компилировались против настоящих зависимостей, тесты не запускались, APK не собирался.**
Единственный способ получить APK: GitHub Actions (`docs/BUILD_AND_INSTALL.md`).

## 1. Запущено и пройдено здесь
- `native-check/run.sh`: тест буфера UTF-8 собран g++ и пройден; синтаксис `norva_llama.cpp` против заглушек `llama.h`.
- Статическая проверка 43 `.kt`-файлов: баланс скобок, существование всех импортов `ai.norva.*`. Это не компиляция.
- Сверка JNI: имена и число параметров всех `external fun` совпадают с C++ (для `nativeGenerate` 12 и 12).
- Арифметика бюджета памяти (числа в `docs/DEVICE_GT8PRO.md`).
- Проверка YAML workflow (разбирается, 4 job).

## 2. Проверено чтением источников (не сборкой)
- Текст актуального `include/llama.h` (master, ноябрь 2026) прочитан целиком и сверен с каждым вызовом `norva_llama.cpp`.
- Поддержка Qwen3.5 в llama.cpp: архитектура `qwen35`, влита 10.02.2026 (PR #19468). Для CPU работает; Vulkan для DeltaNet-слоёв не готов, поэтому GPU не используется.
- Рекомендованный сэмплинг Qwen3.5-4B (карточка): с рассуждениями temp 1.0, top_p 0.95, top_k 20, presence_penalty 1.5; без них 0.7 / 0.8 / 20 / 1.5.
- Qwen3.5-2B: `unsloth/Qwen3.5-2B-GGUF`, файл `Qwen3.5-2B-Q4_K_M.gguf`, 1 280 835 840 байт (по сторонним зеркалам). Qwen3.5-4B: 2,74 ГБ, Apache-2.0.
- Версии: KSP `2.0.21-1.0.28` есть на Maven Central; AGP 9.4 требует Gradle 9.6 (поэтому закреплён AGP 8.7.3); актуальные мажоры GitHub Actions.

## 3. Написано, но не компилировалось и не запускалось
- `core-policy`, `core-inference`, `core-chat` и их тесты (включая 15 тестов оркестратора на тестовых двойниках и 4 теста `CpuGuard`).
- `engine-llama` (JNI, CMake, Kotlin-обёртка) и `app` (Room, Compose, провайдеры памяти и нагрева).
- CI: `jvm-tests`, `native-stub-check`, `llama-api-check`, `android-apk` (артефакт `norva-ai-debug-apk`).

## 4. Исправлено на этом этапе
1. Не было `gradle.properties`: без `android.useAndroidX=true` сборка `:app` падала бы. Добавлен.
2. JNI не совместим с актуальным `llama.h`: поле `use_mmap` удалено (теперь `load_mode`), `llama_sampler_init_penalties` принимает `n_vocab`.
   Исправлено; различия версий выбираются через SFINAE.
3. Версия llama.cpp не была закреплена: `llama.cpp.version` = `b12591`, `scripts/fetch_llama.sh`, CI берёт тег из этого файла.
4. Параметры Qwen3.5: добавлен `presence_penalty` (Kotlin, JNI, C++), температуры приведены к карточке модели.
5. Режим рассуждений: промпт теперь заканчивается открытым `<think>\n`, поток разбирается с `startInThinking`; тесты обновлены.
6. Квантованный KV-кэш: при неудаче создания контекста повтор с f16 вместо отказа.
7. Защита от SIGILL (`CpuGuard`): сборка с i8mm сверяется с `/proc/cpuinfo`.
8. `ComponentCallbacks2.TRIM_MEMORY_BACKGROUND` вместо неразрешимой простой константы; явный сериализатор в `Hub.kt`; CMake: `LLAMA_OPENSSL=OFF`, `GGML_LLAMAFILE=OFF`.
9. Каталог: Qwen3.5-2B подтверждён (размер, репозиторий). CI переписан на актуальные версии действий.

## 5. Не реализовано
- Облачный ИИ и гибридный режим: по условию этапа не начинался, пока локальный ИИ не заработает на устройстве.
- Долговременная память, документы, голос, изображения, видео, персонажи и анимации, настоящее размытие фона.
- Фоновая загрузка моделей и foreground service для генерации, второй проход проверки в Deep, повторное использование KV-кэша, markdown, иконка, подпись release.
- Встроенный бенчмарк и калибровка бюджета памяти на устройстве.

## 6. Оставшиеся риски (проверить в таком порядке)
1. Первая сборка: ошибки Kotlin/Compose/Room/Gradle возможны, ни одна часть не компилировалась.
2. `llama-api-check`: `b12591` это ночная сборка; я читал `llama.h` с master, а не с этого тега. Если job красный, правится `norva_llama.cpp`.
3. Совпадение формата промпта с шаблоном Qwen3.5 из GGUF не проверялось; предположение о `<think>\n` в начале рассуждения не проверено.
4. Квантованный KV при flash attention на CPU для гибридной модели Qwen3.5 не проверялся (есть откат на f16).
5. Наличие i8mm у Snapdragon 8 Elite Gen 5 предполагается; при отсутствии `CpuGuard` покажет ошибку.
6. Входы `gradle-version` у `setup-gradle@v6` и `android-actions/setup-android@v4` не проверялись на реальном запуске.
7. Версии Gradle, AGP, Kotlin, Compose старше актуальных; переход на AGP 9.x это отдельная работа.
8. Отмена во время prefill срабатывает после него; Android может заморозить процесс в фоне; оценка KV для гибридной модели завышена.
